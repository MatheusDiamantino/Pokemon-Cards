# Pokémon Cards

Projeto de estudo que simula a abertura de um pacote de cartas Pokémon (Base Set) com JavaScript.

🔗 **Demo:** https://matheusdiamantino.github.io/Pokemon-Cards/

## O que foi praticado

- Manipulação do DOM: criação dinâmica dos cards a cada clique no pacote
- Sorteio de cartas com `Math.random`
- HTML e CSS para o layout das cartas

## Como abrir

Abra o `index.html` com um servidor local (ex.: Live Server) e clique no pacote para abrir 11 cartas aleatórias.
